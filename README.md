# Desarrollo Web: Tienda de Cosméticos

## Descripción

Este proyecto consiste en el desarrollo de una aplicación web para una cadena de tiendas de cosméticos, con una interfaz inspirada en plataformas de comercio electrónico del sector.

La aplicación permite explorar productos y categorías, realizar búsquedas, consultar servicios y promociones, y gestionar reseñas de clientes. Además, integra una base de datos relacional diseñada y desarrollada previamente en el proyecto de **Diseño de Bases de Datos**, conectada con la aplicación mediante PHP y PDO.

El proyecto combina tecnologías frontend y backend para desarrollar una plataforma web dinámica e interactiva, aplicando conocimientos de programación web y gestión de bases de datos.

## Objetivos

- Desarrollar una aplicación web utilizando diferentes tecnologías de programación.
- Diseñar una interfaz visual organizada e intuitiva.
- Facilitar la búsqueda y consulta de productos y categorías.
- Incorporar funcionalidades relacionadas con servicios, promociones y reseñas.
- Integrar y conectar una base de datos relacional previamente diseñada.
- Aplicar conocimientos de desarrollo frontend y backend.

## Herramientas utilizadas

- **HTML:** estructura y organización del contenido.
- **CSS:** diseño y presentación visual.
- **JavaScript:** funcionalidades e interactividad.
- **PHP:** desarrollo de la lógica del servidor.
- **SQL:** consultas y gestión de la información.
- **PDO:** conexión entre PHP y la base de datos.
- **MySQL:** sistema gestor de bases de datos.
- **XAMPP:** entorno de desarrollo local.

## Desarrollo del proyecto

1. **Diseño de la interfaz**
   - Estructuración de las páginas mediante HTML.
   - Aplicación de estilos con CSS.
   - Organización visual de las distintas secciones de la tienda.

2. **Desarrollo frontend**
   - Implementación de funcionalidades con JavaScript.
   - Navegación por categorías y secciones.
   - Incorporación de herramientas de búsqueda de productos.

3. **Integración de la base de datos**
   - Reutilización de la base de datos relacional diseñada y desarrollada previamente en el proyecto de Diseño de Bases de Datos.
   - Integración de las tablas y relaciones en la aplicación web.
   - Utilización de MySQL para almacenar y recuperar información.

4. **Desarrollo backend**
   - Implementación de funcionalidades mediante PHP.
   - Conexión con la base de datos utilizando PDO.
   - Ejecución de consultas SQL para recuperar y gestionar información.

5. **Funcionalidades de la aplicación**
   - Búsqueda de productos por diferentes criterios.
   - Consulta de categorías, servicios y promociones.
   - Inserción, actualización y eliminación de reseñas.
   - Consulta de opiniones y filtrado por puntuación.

## Resultados

El proyecto dio lugar a una aplicación web que integra una interfaz interactiva con una base de datos relacional. Se consiguió conectar el diseño de la base de datos desarrollado previamente con una aplicación web funcional, permitiendo consultar y gestionar información mediante distintas funcionalidades.

Su desarrollo permitió aplicar conocimientos de diseño web, programación frontend y backend, gestión de información y comunicación entre una aplicación y un sistema de bases de datos.

## Cómo ejecutar el proyecto

La aplicación está diseñada para ejecutarse en un entorno local mediante XAMPP.

1. Instalar y abrir XAMPP.
2. Iniciar los servicios Apache y MySQL.
3. Copiar la carpeta del proyecto dentro del directorio `htdocs`.
4. Acceder a phpMyAdmin e importar el archivo tienda_BD.sql, situado en la carpeta adj del proyecto.
5. Configurar los datos de conexión a la base de datos en los archivos correspondientes.
6. Abrir el navegador y acceder a:

   `http://localhost/nombre-del-proyecto/0. pag_inicial.html`
