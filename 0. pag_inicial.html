Introducción

En un mercado cada vez más competitivo y orientado al cliente, la gestión eficiente de la información es fundamental para el éxito de cualquier negocio. Este proyecto presenta una plataforma web diseñada para una cadena de tiendas de cosméticos, con el objetivo de optimizar la organización, visualización y manejo de datos clave relacionados con productos, clientes, empleados, proveedores y servicios.

Este proyecto ha sido desarrollado en el marco de la asignatura de Bases de Datos, con el propósito de aplicar de forma práctica los conocimientos adquiridos durante el segundo cuatrimestre del curso. La propuesta consiste en el diseño e implementación de una plataforma web orientada a la gestión de datos para una cadena de tiendas de cosméticos, integrando aspectos clave como la organización de productos, la interacción con clientes y la administración de servicios.

A lo largo del desarrollo del trabajo se han puesto en práctica los fundamentos de HTML, CSS, JavaScript y PHP, tecnologías vistas durante el cuatrimestre y que permiten construir aplicaciones dinámicas e interactivas. En concreto, se ha diseñado una interfaz intuitiva y funcional que permite al usuario buscar productos, explorar distintas categorías, acceder a servicios y promociones, así como enviar y consultar reseñas de clientes.

Este sistema simula un entorno real de gestión comercial, donde la información está interconectada y puede ser consultada y manipulada de manera eficiente. Con ello, se demuestra no solo el dominio técnico de las herramientas aprendidas, sino también la capacidad para aplicarlas en el desarrollo de soluciones prácticas y útiles en el contexto de una aplicación web con base de datos.
